# Development and training of a classifier for automatic ethnicity recognition in AI-generated images

This repository contains the code and experimental setup for my BA thesis project, centered on evaluating ethnic and gender bias in computer vision models. The project consisted in the fine-tuning of a ResNet-50 architecture for an ethnic image classification task using synthetic images generated by a Text-to-Image (TTI) language model, analyzing how pre-existing dataset biases directly impact classifier performance and generalizability.

## 📌 Project Overview
The primary objective of this study was to investigate social biases (ethnic and gender-based) embedded within generative and predictive AI models:
* <b>Generative side:</b> Evaluating bias in synthetic image datasets produced by Text-to-Image (TTI) models portraying individuals across diverse ethnic groups, genders, and professional contexts.
* <b>Predictive side:</b> Assessing how an image classifier trained on synthetic TTI data inherits, reflects, and amplifies these intrinsic biases across different sampling and class-balancing conditions.

## 🛠️ Methodology & Architecture
* <b>TTI model:</b> Stable Diffusion 2.1.
* <b>Classifier architecture:</b> ResNet-50.
* <b>Dataset composition:</b> Synthetic images depicting individuals of various ethnicities and genders across different workplace/professional settings.
* <b>Experimental setup:</b> Three distinct classification experiments conducted under different class-balancing techniques (e.g., undersampling).

## 📊 Key Findings & Results

All three experimental setups demonstrated significant performance degradation when making predictions on classes outside the dominant (Caucasian) group, regardless of the class-balancing technique applied.

Main insights:
* Class balancing alone does not remove intrinsic bias. The underlying TTI generative model produces limited intra-class diversity for minority groups, leading to insufficient feature representation.
* While undersampling improves overall quantitative distribution, reducing sample size limits the model's exposure to intra-class variance, further impairing generalization performance.
* Ethnicity and gender are non-rigid, evolving, and overlapping categories; facial features (skin tone, structure) exhibit vast intra-group variance.
* Single-dimensional classifiers fail to account for intersecting identity layers (e.g., a model trained predominantly on white individuals suffers performance drops not just for black individuals, but exponentially more for black women or marginalized socio-economic subgroups).
* Environmental factors such as lighting, camera angles, and image quality in synthetic generations add layers of noise that hinder consistent feature extraction.
